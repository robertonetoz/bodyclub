# Fotos do site

Coloque as fotos com estes nomes. Enquanto um arquivo não existir, o site mostra um espaço reservado com o caminho esperado.

| Onde aparece           | Arquivo                                   |
|------------------------|-------------------------------------------|
| Fundo do topo (hero)   | `images/fachada.jpg`                      |
| Seção Estrutura        | `images/estrutura.jpg`                    |
| Modalidades            | `images/modalidades/musculacao.jpg`, `funcional.jpg`, `power-bike.jpg`, `avaliacao.jpg`, `personal.jpg`, `nutricao.jpg` |
| Galeria (12 fotos)     | `images/galeria/01.jpg` até `12.jpg`      |

Para mudar a quantidade de fotos da galeria, os nomes ou as legendas, edite `src/data/site.ts`.
Dica: use fotos em .jpg com no máximo ~2000px de largura para o site carregar rápido.
